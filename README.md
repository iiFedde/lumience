# Stanicdesign — 1:1 clone

Replica van [stanicdesign.nl](https://stanicdesign.nl/) gebouwd met React, Vite en Tailwind CSS.

## Starten

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Pagina's

- `/` — Home
- `/portfolio` — Portfolio
- `/services` — Diensten
- `/contact` — Contact
- `/offerte` — Offerte-stappenplan
- `/privacy`, `/cookies`, `/voorwaarden` — Juridisch
